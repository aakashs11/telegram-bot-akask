# Phase 4: Smart Features

**Timeline:** Week 7–9  
**Dependencies:** Phase 3 (content must be indexed in pgvector for all features to work)  
**Goal:** Turn ASK AI into a genuine study companion — not just Q&A, but exam prep, video notes, study planning, and self-testing.

---

## User Stories

1. **As a CBSE student**, when I ask a doubt, the answer should match board exam format (1-mark, 2-mark, 5-mark style).
2. **As a student preparing for boards**, I want sample paper questions with model answers.
3. **As a student**, I want to watch a YouTube video and get auto-generated notes from it.
4. **As a student confused about where to start**, I want a study planner that helps me cover the syllabus efficiently.
5. **As a student**, I want to test myself with MCQs on a topic.

---

## Feature Specs

### F1: CBSE Doubt Solving (Auto-Detect Format)

**What it does:** Automatically detects the type of answer a student needs from their query phrasing and responds in the appropriate CBSE board exam format.

**Detection rules:**

| Student says | Detected format | Response style |
|---|---|---|
| "explain X" | Detailed conceptual | 3-5 mark style with diagrams/examples described |
| "define X", "what is X" (short) | 1-2 mark definition | Crisp, textbook-accurate definition |
| "discuss X", "describe X" | 3-5 mark board answer | Structured with points, intro, conclusion |
| "answer" explicitly | Board exam model answer | Full marks scheme with marking breakdown |
| "difference between X and Y" | Comparison table | Tabular format (minimum 4 points) |
| "list", "name", "give examples" | Enumeration | Numbered points, concise |

**Implementation:**
- Add format-detection logic to the system prompt (not hardcoded Python rules)
- System prompt includes CBSE marking scheme guidelines per subject
- All answers cite CBSE textbook chapters when possible
- Guardrail: must align with NCERT/CBSE curriculum, not generic internet knowledge

**Changes:**
- `telegram_bot/prompts/agent_system.md` — add CBSE format detection instructions and marking scheme reference
- `telegram_bot/services/agent_service.py` — pass detected format as context to LLM

### F2: Board Exam Prep

**What it does:** Provides previous year questions (PYQs), sample paper questions, and model answers for specific topics, weighted by mark distribution.

**New tool:** `ExamPrepTool`

```
Parameters:
  - class: str (required) — "10", "11", "12"
  - subject: str (required) — "AI", "CS", "IT", "IP"
  - topic: str (optional) — specific topic to focus on
  - question_type: str (optional) — "pyq", "sample", "model_answer"
  - marks: int (optional) — 1, 2, 3, 5 (filter by mark value)
```

**Data source:**
- PYQs scraped from CBSE archives and stored in content_chunks with `source_type = 'pyq'`
- Model answers generated by GPT-4o from PYQs + NCERT content, reviewed by admin
- Mark distribution data from CBSE syllabus documents (which topics carry how many marks)

**Features:**
- Returns PYQs with model answers
- Sample paper generation: LLM generates exam-style questions from indexed content for a topic
- Mark-distribution awareness: focuses recommendations on high-weight topics
- "Most repeated" flag: tracks which PYQ topics appear across multiple years

**New files:**
- `telegram_bot/tools/exam_prep_tool.py`
- `telegram_bot/services/exam_prep_service.py`
- `scripts/ingest_pyq_papers.py` — bulk ingest CBSE PYQ PDFs

**Database:**

```sql
CREATE TABLE exam_questions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    class TEXT NOT NULL,
    subject TEXT NOT NULL,
    year INTEGER,                   -- exam year (NULL for generated questions)
    question_text TEXT NOT NULL,
    model_answer TEXT,
    marks INTEGER NOT NULL,
    topic TEXT,
    chapter TEXT,
    question_type TEXT NOT NULL CHECK (question_type IN ('pyq', 'sample', 'generated')),
    frequency INTEGER DEFAULT 1,    -- how many years this question appeared
    embedding VECTOR(768),
    created_at TIMESTAMPTZ DEFAULT now()
);

CREATE INDEX idx_exam_questions_class_subject ON exam_questions (class, subject);
CREATE INDEX idx_exam_questions_topic ON exam_questions (topic);
```

### F3: Video Notes

**What it does:** Generates structured revision notes from any YouTube video — either by URL or by searching the channel for a topic.

**New tool:** `VideoNotesTool`

```
Parameters:
  - video_url: str (optional) — direct YouTube URL
  - topic: str (optional) — search channel for this topic (at least one of url/topic required)
  - format: str (optional) — "detailed", "quick_revision", "flashcards" (default: "detailed")
```

**Output format (detailed):**

```
📝 Video Notes: {video_title}
🎥 Watch: {video_url}

## Key Concepts
1. {concept} — {explanation} [⏱️ {timestamp}]
2. ...

## Important Definitions
- {term}: {definition} [⏱️ {timestamp}]

## Summary
{3-4 sentence summary of the entire video}

## Quick Revision Points
- {point 1}
- {point 2}
- ...
```

**Implementation:**
- If video_url provided: fetch transcript from content_chunks (already ingested in Phase 3) or ingest on-the-fly
- If topic provided: search content_chunks for YouTube source_type matching topic, pick best match
- Pass transcript chunks to Gemini Flash with structured notes prompt
- Include key timestamps so students can jump to specific concepts
- "Quick revision" format: bullet points only, no explanations
- "Flashcards" format: Q&A pairs for self-testing

**New files:**
- `telegram_bot/tools/video_notes_tool.py`
- `telegram_bot/services/video_notes_service.py`

### F4: Study Planner

**What it does:** Generates a personalized study plan based on the student's class, subject, available time, and weak areas — using memory (what they've studied) and content index (what's available).

**New tool:** `StudyPlannerTool`

```
Parameters:
  - class: str (required)
  - subject: str (required)
  - days_available: int (required) — days until exam or study window
  - weak_topics: list[str] (optional) — topics student struggles with
  - goal: str (optional) — "board_exam", "unit_test", "revision", "start_fresh"
```

**Output format:**

```
📋 Study Plan: {subject} ({days_available} days)

## Day 1: {topic}
- 📖 Read: {resource_name} (Chapter {n})
- 🎥 Watch: {video_title} ({duration})
- ✏️ Practice: {exercise or PYQ suggestion}

## Day 2: {topic}
...

## Day {n}: Revision
- 🔄 Review: {topics from Day 1-3} (spaced repetition)
- 📝 Take quiz on: {topics}

## Weak Area Focus
- Extra time allocated to: {weak_topics}
- Recommended resources: {specific PDFs/videos}
```

**Intelligence:**
- Uses Phase 2 memory to know what the student has already studied (avoid repeating)
- Uses content_chunks index to only recommend resources that actually exist
- Applies Ebbinghaus forgetting curve: schedule review of Day 1 topics on Day 3, Day 7, etc.
- Allocates more time to weak_topics (1.5x weight)
- If goal is "board_exam": prioritize high-mark-weight topics from mark distribution data
- If goal is "revision": skip new content, focus on practice + PYQs

**New files:**
- `telegram_bot/tools/study_planner_tool.py`
- `telegram_bot/services/study_planner_service.py`

### F5: Quiz Mode

**What it does:** Interactive MCQ quiz on any topic. Generates questions from indexed content, tracks performance, adjusts difficulty.

**New tool:** `QuizTool`

```
Parameters:
  - class: str (required)
  - subject: str (required)
  - topic: str (required)
  - num_questions: int (optional, default: 5, max: 20)
  - difficulty: str (optional) — "easy", "medium", "hard", "adaptive"
```

**Quiz flow:**

```
Student: /quiz AI neural networks
Bot: 🧠 Quiz: Neural Networks (Class 10 AI)
     Question 1/5:

     Which of the following is NOT a type of neural network?
     A) CNN
     B) RNN
     C) SQL
     D) GAN

Student: C
Bot: ✅ Correct! SQL is a database query language, not a neural network.

     Score: 1/1
     Question 2/5: ...

[After all questions]
Bot: 📊 Quiz Complete!
     Score: 4/5 (80%)
     ✅ Strong: Network types, activation functions
     ❌ Review: Backpropagation (watch: NLP One Shot at 14:32)
```

**Implementation:**
- Generate MCQs from content_chunks: pass relevant chunks to LLM with MCQ generation prompt
- Each question has: question_text, options (4), correct_answer, explanation, difficulty, source_chunk_id
- Track quiz sessions in memory (Phase 2): which topics quizzed, scores, weak areas
- Adaptive difficulty: start medium, increase on 2 correct in a row, decrease on 2 wrong
- Wrong answer explanations always cite the source content
- Rate limit: max 3 quizzes per hour per user (prevent abuse)

**State management:**
- Quiz state stored in conversation context (not DB — quizzes are ephemeral)
- Format: `{quiz_id, questions: [...], current_index, answers: [...], score}`
- Quiz ends: summary stored in memory for study planner integration

**New files:**
- `telegram_bot/tools/quiz_tool.py`
- `telegram_bot/services/quiz_service.py`

## Technology Notes

- All features use the Phase 3 RAG pipeline — no new infrastructure needed
- All new tools follow the existing `BaseTool` pattern in `telegram_bot/tools/base.py`
- MCQ generation uses Gemini Flash (free) — quality is sufficient for MCQ format
- Study planner and exam prep use GPT-4o for synthesis (requires reasoning)
- Video notes use Gemini Flash (free) — summarization task, not complex reasoning

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| MCQ quality (bad distractors) | Students learn wrong things | Strict prompt engineering + admin review of generated MCQs |
| PYQ data availability | Incomplete coverage for some subjects/years | Start with AI (71% of users), expand based on demand |
| Study planner over-promising | Plans that don't match actual content | Only recommend resources confirmed in content_chunks |
| Quiz state management in multi-turn | Lost quiz progress | Store quiz state in bot_data conversation dict, timeout after 30 min |
| Format detection errors | Wrong answer style | Include "not sure? ask in board-exam format" hint in responses |
